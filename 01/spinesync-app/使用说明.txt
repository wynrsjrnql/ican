脊智健 SpineSync 桌面版 · 使用说明
====================================

【方式一】开发/演示运行（需 Node.js 环境）
  1. 首次使用：在本目录打开命令行执行  npm install  （联网，约2分钟）
  2. 双击 start.bat 启动；或命令行执行  npm start

【方式二】打包后便携版（无需 Node.js）
  1. 执行：npm run pack
  2. 生成目录：dist\SpineSync-win32-x64\
  3. 双击其中 SpineSync.exe 即可运行，整个文件夹可拷贝到 U 盘带去答辩现场
